## Goal

One script that checks tennis court availability across all the booking sites Steve and Irene use (around Newington Green and Tottenham), instead of clicking between websites. Run it once and see what's free today or over the coming week.

## Files

- `court_finder.py` is the whole tool: venue config, both adapters, CLI, and the HTML generator.
- `courts.html` is generated by `--html`. It's a snapshot, not live.
- `probe_output/` holds raw ClubSpark JSON from the first probe (reference only).
- `better_token.txt` is optional and not currently needed. It's a fallback if Better ever starts requiring login. Treat it like a password.

Environment: Windows, run with `py`, from `D:\projects\tennis court finder`. The only dependency is `requests`.

## Usage

```
py court_finder.py                          today, all venues
py court_finder.py --days 7 --after 17:00   next week, evenings
py court_finder.py --area irene --min 90    Newington Green side, 90+ min runs
py court_finder.py --venue clissold         one venue
py court_finder.py --html                   week-ahead page in the browser
py court_finder.py --debug highbury         raw data dump for one venue
```

The flags are `--days`, `--start YYYY-MM-DD`, `--after HH:MM`, `--before HH:MM`, `--min MINUTES`, `--area home|irene|all`, `--venue TEXT`, `--html` and `--debug VENUE`. The default look-ahead is 1 day, or 7 with `--html`.

## How each platform works

### ClubSpark (LTA)

- Endpoint: `https://clubspark.lta.org.uk/v0/VenueBooking/{slug}/GetVenueSessions?resourceID=&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD&roleId=`
- Works with a plain request and a browser-like User-Agent.
- The response contains `Resources` (courts), then `Days`, then `Sessions`. Times are minutes from midnight (420 = 07:00).
- **Availability rule:** a session with `Category 0` and `Capacity > 0` is an open window. Any other session blocks the time it covers. The open windows are cut into `Interval`-length slots. This was checked against the live site.
- The script fetches in 7-day chunks. Haringey parks book up to 7 days ahead.
- Booking link format: `https://clubspark.lta.org.uk/{slug}/Booking/BookByDate#?date=YYYY-MM-DD&role=guest`
- `Cost` is per hour. £0.00 slots are genuinely free, typically weekday daytime at Chestnuts and Downhills.

### Better (GLL)

- Endpoint: `https://better-admin.org.uk/api/activities/venue/{venue}/activity/{activity}/v2/times?date=YYYY-MM-DD`
- The headers needed are `Origin: https://bookings.better.org.uk` and `Referer: https://bookings.better.org.uk/`. No auth is required.
- There's one request per day, and each entry is one hour across all courts (`"location": "Multiple"`). `spaces` is the number of courts free. **Availability rule:** `spaces > 0`, and `first_bookable_at` has already passed.
- **A 422 response means the date isn't released yet.** The script stops at that point and keeps the earlier days. Slots appear to release at 22:00, six days ahead.
- Booking link format: `https://bookings.better.org.uk/location/{venue}/{activity}/YYYY-MM-DD/by-time`
- If it ever returns 401 or 403, the script retries with the token from `better_token.txt`.

## HTML page

- A day tab for each day, showing how many court-hours are free.
- A grid with a row per venue and a column per hour. Each cell shows the number of free courts, styled as a court: green surface, white lines, and tennis-ball yellow for free slots, brighter when more courts are free. Clicking a cell opens that venue's booking page for that day.
- Area toggle (All / Tottenham / Newington Green) and minimum length toggle (1h+ / 1.5h+ / 2h+).
- A list under the grid of continuous runs, each with a Book link.
- On mobile, the venue column stays pinned and the grid scrolls to the first free hour.
- Fonts: Barlow and Barlow Condensed (Google Fonts). Dark mode is supported.
